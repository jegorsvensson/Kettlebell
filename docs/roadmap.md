# Roadmap – Kettlebell

## Fas 0: Setup (dag 1–2)
- Repo‑struktur + linting (React/TS).
- Grundläggande CI (lint/test).
- Design tokens (typografi, spacing, färger).

## Fas 1: MVP‑kärna (vecka 1–2)
**Mål:** En användbar canvas där man kan placera och spara tasks + filer.

**Leverabler**
1. **Canvas view**
   - Pan + zoom
   - Grid + snap
2. **Cards**
   - Task card: titel + status
   - File card: image/pdf preview
3. **Upload & resize**
   - Drag & drop upload
   - Direkt resize handles + presets
4. **Persistens**
   - Spara position, storlek, typ
5. **Frames**
   - Skapa ramar, sätt titel, exportera som bild

## Fas 2: Samarbete (vecka 3–4)
- Realtime cursors
- Live updates för cards
- Kommentarsystem per card

## Fas 3: Prototyper + extern integration
- Figma/Framer embed
- API för att synca tasks
- Export (PDF, PNG, CSV)
