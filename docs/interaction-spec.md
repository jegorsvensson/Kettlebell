# Interaction spec (MVP)

## Pan & zoom
- Trackpad/mouse wheel zoom med center‑point under cursor.
- Space + drag för pan (alternativt middle‑mouse).
- Min/max zoom: 0.1×–4×.

## Card‑interaktioner
- Drag card = flytta på canvas.
- Resize card (bilder) = hörn‑handles med fri skala + presets (S/M/L).
- Select card = border + quick actions (duplicate, delete).

## Upload‑flöde
1. Drag & drop filer på canvas.
2. Auto‑place card nära drop‑point.
3. Visa resize‑handles direkt efter drop.
4. “Done” när användaren klickar utanför eller trycker Enter.

## Frames
- Drag för att skapa frame‑rektangel.
- Frame kan innehålla cards och flyttas som grupp.
- Exportera frame till PNG (MVP: enkel export).
