# User stories

## Canvas
- Som användare vill jag kunna pan/zoom på en oändlig yta så att jag alltid kan hitta och arrangera mitt innehåll.
- Som användare vill jag kunna skapa frames för att gruppera objekt och skapa struktur.

## Tasks
- Som användare vill jag skapa ett task‑kort med titel och status för att snabbt kunna planera.
- Som användare vill jag kunna dra task‑kort runt fritt för att ändra prioritet visuellt.

## Filer
- Som användare vill jag dra in en bild och direkt kunna ändra storlek utan extra dialoger.
- Som användare vill jag kunna förhandsgranska pdf‑filer direkt på canvas.

## Prototyper
- Som användare vill jag embedda Figma/Framer‑prototyper i kort för att visa flöden.
